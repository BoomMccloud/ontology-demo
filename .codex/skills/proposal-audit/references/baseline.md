# Baseline scenario

Before this skill existed, the audit correctly identified that the protected witness had been weakened and that the test-file edit exceeded approved scope. It also retained the useful conclusion that those are correctable reasons to recommend `REVISE`.

The baseline nevertheless called the primary claim satisfied because the reported response showed unavailable-page copy, despite the decisive witness having been compromised. It also prescribed restoring a 404 response, which exceeds the accepted claim that users cannot enter through the guest link. The skill therefore preserves the independent witness and scope checks, but requires `UNPROVED` for a compromised decisive witness and confines the recommendation to restoring proof rather than prescribing a new status-code contract.
