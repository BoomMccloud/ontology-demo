# Stock Ontology proposals

This folder holds product epics and proposal ledgers for Stock Ontology.

## What's in this folder

- [`epics/`](epics/) holds one file per product epic. Each file describes the intended outcome, benefits, and draft user journey, with phasing and dependencies where relevant.
- The Markdown files alongside this README are proposal ledgers. Each ledger tracks one change through the proposal pipeline and records decisions, implementation, verification, and audit results as the work progresses.

## How to use it

Draft and review the product outcome and user journey in the epic file. When a change is ready for the proposal pipeline, create a ledger for that change and link to the epic where applicable. Follow the repository's [proposal workflow](../../AGENTS.md#change-process-proposal-pipeline) for framing, implementation, and review.
